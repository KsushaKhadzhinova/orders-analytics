# Контекст проекта

## Что это
Учебный dbt-проект `orders-analytics` из комплекта сертификации Accelerator (версия 0.18.0, каталог навыков v1.3.0). Хранилище: DuckDB, файл `orders.duckdb` создаётся командами `dbt seed` и `dbt build` и в репозиторий не входит.

## Цель
Пройти упражнения 01 и 02 комплекта (упражнение 03 необязательное), затем применить Accelerator к другому, веб-проекту. Для этого собран гайд с отчётом в одном файле, а упражнение 02 пройдено отдельно как эталон для сравнения.

## Что лежит в репозитории
| Путь | Что |
|---|---|
| корень (`models`, `seeds`, `dbt_project.yml`, `profiles.yml`, `requirements.txt`, `ORDER-STATUSES.md`) | учебный проект в исходном состоянии упражнения 02 (тесты ещё не добавлены) |
| `.accelerator/profile.json`, `registry.json`, `.claude/skills/` | результат упражнения 01: профиль, реестр, три навыка |
| `_steps/` | скрипт шага 2 упражнения 02 и инструкция с промптом для веб-проекта |
| `docs/guide-and-report.html` | **главный файл**: гайд, теория, разбор задания и отчёт с скриншотами в одном HTML |
| `docs/artifacts/` | отдельные страницы: «Карта комплекта», «Журнал», «Разбор проекта» |
| `docs/dialog.md` | диалог с ассистентом (читаемая версия) |
| `docs/context.md` | этот файл |
| `reference/` | **эталонное решение упражнения 02**: 14 тестов, карантин плохих строк, настоящие выводы dbt в `_run/` |

## Как устроено на машине (Windows 11)
| Что | Где |
|---|---|
| Команда `accelerator` | `E:\accelerator\bin\accelerator.ps1`, версия 0.18.0 |
| Плагин Claude Code | `accelerator@accelerator-installation`, область user |
| Исходный комплект | `E:\accelerator-kit` (в репозиторий не добавлен: это материалы компании) |
| Рабочий проект | `E:\orders-analytics` |
| Python | `py -3.11` (3.11.9); `python` в PATH — 3.9, `py` по умолчанию — 3.13 из Anaconda, для dbt 1.7 не подходит |
| Окружение | `.venv` в проекте: dbt-core 1.7.9, dbt-duckdb 1.7.5, одна команда pip для манифеста и адаптера |

## Что сделано
1. Accelerator перенесён на диск E:, старая установка удалена.
2. Упражнение 01: `accelerator scan -ToolsetRef refs/tags/v1.3.0`, профиль `claude-code` + темы `data-quality`, `testing`, установлены `DBT-LAYER-BOUNDARIES`, `DBT-MODEL-TESTING`, `PYTEST-DATA-PIPELINES` (0.1.1).
3. Упражнение 02, шаги 1–2: окружение, сиды, замена `source()` на `ref()`, `dbt build` зелёный (PASS=9).
4. Эталон упражнения 02 пройден в `reference/`: красный `dbt test` (PASS=12, ERROR=2 из 14), разбор падений, зелёный (PASS=14).
5. Собран единый файл гайда и отчёта `docs/guide-and-report.html`.
