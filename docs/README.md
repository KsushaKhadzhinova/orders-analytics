# Документация

| Файл | Что внутри |
|---|---|
| [guide-and-report.html](guide-and-report.html) | **Главный файл.** Гайд с нуля (48 шагов), разбор задания, теория по Claude, ИИ, упражнениям и dbt, разбор файлов проекта, тренажёр тестов, вопросы защиты и отчёт со скриншотами в каждом шаге. Открывается двойным щелчком, работает без интернета |
| [context.md](context.md) | Контекст: цель, как устроена машина, что сделано и что осталось |
| [dialog.md](dialog.md) | Диалог с ассистентом (реплики, без служебных блоков) |
| [artifacts/kit-map.html](artifacts/kit-map.html) | Карта комплекта Accelerator |
| [artifacts/journal.html](artifacts/journal.html) | Журнал |
| [artifacts/project-guide.html](artifacts/project-guide.html) | Разбор проекта (схемы, теория, симулятор) |
| [../reference/](../reference/README.md) | Эталонное решение упражнения 02 с настоящими выводами dbt |

Отчёт в `guide-and-report.html` сохраняется в браузере, где вы его открыли. Скачайте отчёт файлом или резервную копию JSON, чтобы не потерять записи.

Файлы на GitHub открываются как текст. Чтобы увидеть страницы, скачайте `.html` и откройте их локально.
